## 123. Canonical Release 1 Scope — היקף Release 1 הקנוני

(נוסף ב־29.09.2026 · ADR-002 · CL-0002/CL-0008/CL-0009)

### עיקרון
**Release = Capabilities. Stages = סדר מימוש.**
מוכנות Release נקבעת לפי השלמת Capabilities ולא לפי מספרי שלבים. Release עתידי מוגדר קודם כסט Capabilities, ורק אחר כך ממופה לשלבי 23A.

### Release 1 — חייב לכלול
Sources · Document Intake · Processing · Evidence · Canonical Model · Reconciliation · Current Financial Picture · Accounting · VAT · Coverage · Review Queue · Mobile · RTL · Security · Backup · Restore

### Release 2 — נדחה במפורש (אינו חוסם Release 1)
Historical Investigation · Planning · Forecast · Scenarios · Recovery · Advanced AI Assistant

### מיפוי לשלבי 23A
Release 1 = שלבים **0–14, 19, 20**.
שלבים 15, 16 ו־17 שייכים ל־Release 2. שלב 18 (אינטגרציות API) נדחה.

### מקורות ב־Release 1
חשבונית ירוקה ובנק נקלטים כ**קבצי ייצוא** דרך מסלול ה־Ingestion הקנוני. API נדחה לשלב 18 (23A §107).

### כלל
Capability שנדחתה מסומנת "Deferred — not part of Release 1" (23D §113). אין מימוש חלקי של Release 2 בתוך Release 1.
